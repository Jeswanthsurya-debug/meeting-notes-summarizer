# meeting-notes-summarizer
# 📝 Meeting Intelligence Hub

An AI-powered meeting notes summarizer built with Python Flask and Google's Gemini AI. Features integrated real-time speech recognition (Voice Input) and browser-native Text-to-Speech playback.

---

## ✨ Key Features
* **🎙️ Live Voice Input:** Integrated Web Speech API for real-time meeting transcription.
* **⚡ AI Summarization:** Distills complex transcripts into concise executive summaries using Gemini AI.
* **💡 Decision & Task Extraction:** Automatically identifies key agreements and actionable items.
* **🔊 Read Out Loud:** Built-in Speech Synthesis to hear summaries spoken aloud.
* **🎨 Modern UI:** Single-file glassmorphism interface.

---

## 🛠️ Tech Stack
* **Backend & Frontend:** Python Flask (`render_template_string`), HTML5, CSS3, JavaScript
* **AI Engine:** Google Gemini API (`google-generativeai`)
* **Voice APIs:** Web Speech API (Recognition & Synthesis)
